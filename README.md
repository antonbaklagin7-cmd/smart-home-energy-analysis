# Анализ энергопотребления бытовых приборов в умных домах

## Цель
Выяснить, какие приборы, часы суток и внешние условия определяют потребление электроэнергии в умных домах в 2023 году и какие ожидаемые закономерности (реакция HVAC на температуру, эффект размера семьи, пики нагрузки) действительно подтверждаются данными.

## Данные
Kaggle, *Smart Home Energy Consumption* (`smart_home_energy_consumption_large.csv`). 100 000 строк × 8 столбцов, период 01.01.2023 — 01.01.2024. Одна строка — одно событие прибора в домохозяйстве (500 домов, 10 типов приборов). Набор, по всей видимости, **синтетический**.

## Что сделано
- Проверка качества и очистка: удалено 4 дубля события, стабилизирован размер семьи, пересчитан сезон по месяцу (исходное поле `season` не соответствует календарю).
- Исследовательский анализ с выводами после ключевых графиков, поиск выбросов.
- Проверка гипотез H1–H3 с размерами эффекта; результаты в `results/hypothesis_tests.csv`.
- ABC-XYZ анализ приборов и домохозяйств (`results/abc_xyz.xlsx`).
- RFM не выполнялся: в данных нет клиентов и покупок.
- Дашборд DataLens.

## Основные выводы
1. Air Conditioning и Heater дают около половины всего потребления (≈ 47%); остальные приборы, кроме холодильника, дают близкие доли. Приоритет для управления нагрузкой и подсказок по экономии — HVAC.
2. Концентрации потребления нет: топ-10% домов дают ≈ 11.7% (при равномерном 10%), топ-3 часа — ≈ 12.8% (при равномерном 12.5%). Основы для «пиковых тарифов» и адресного энергоаудита в данных нет.
3. HVAC не реагирует на наружную температуру (ρ ≈ 0, доля «несоответствующих» включений ≈ 50% во всех зонах); гипотеза H2 о межсезонье **не подтверждена** (p = 0.756).
4. Гипотезы H1 и H3 тоже **не подтверждены**: без деления на размер семьи различий между группами нет (p = 0.241, η² ≈ 0), а среди пиковых дом-часов несколько приборов одновременно работают лишь в 19.1% (наложение приборов вообще редкость: 1.2% дом-часов). Полная таблица — `results/hypothesis_tests.csv`.

**Главное ограничение:** данные синтетические, поэтому отсутствие ожидаемых закономерностей не означает их отсутствия в реальных домах; выводы нельзя переносить на реальные данные без перепроверки.
